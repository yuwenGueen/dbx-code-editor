# 更新日志 / Changelog

## v0.1.17 · 2026-09-28

### 中文

- 新增 Word 导入：将 .docx 转为可恢复的临时 Markdown 草稿，支持标题、列表、表格、链接和图片预览；保存时一并导出图片资源。
- 修复暗色模式下全选文字时选区过亮、语法高亮不清晰的问题。
- 补齐常用 VS Code 快捷键，包括移动或复制行、注释、多光标、代码折叠、查找替换和跳转。
- 新增版本更新说明：升级后首次打开会显示，也可以从帮助菜单或命令面板再次查看。
- 修复 Windows 构建时更新日志换行符导致的校验失败，统一跨平台发布检查。

### English

- Import .docx documents as recoverable Markdown drafts with headings, lists, tables, links, and image previews. Export images alongside the saved Markdown file.
- Improved selection contrast and syntax readability in dark mode.
- Added familiar VS Code shortcuts for line editing, comments, multiple cursors, folding, find and replace, and navigation.
- Added versioned What's New notes shown once after an update and available from the Help menu or command palette.
- Fixed release-note validation for Windows line endings across platform builds.
